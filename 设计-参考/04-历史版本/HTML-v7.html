MyPilot 是典型的三层架构：客户端层是 macOS SwiftUI 原生应用，中继层是 Node.js daemon（mypilot-link），AI 引擎是 OpenClaw Core。我需要清晰地解释每一层的职责。

MyPilot 是一个典型的客户端-服务端架构，主要分为三层：

📱 客户端层 — MyPilot App

macOS 原生 SwiftUI 应用。NavigationSplitView 布局，负责 UI 渲染、消息持久化、本地搜索。通过 WebSocket 与中继层通信。

🔗 中继层 — MyPilot Link

Node.js daemon，npm 全局安装。提供本地 HTTP API（端口 52378），WebSocket 中继，设备身份管理和配对码认证。

🧠 AI 引擎 — OpenClaw Core

模型推理与 Agent 调度。支持多模型切换（火山引擎、DeepSeek、OpenAI），Agent 文件系统（SOUL.md、AGENTS.md），搜索服务集成。
