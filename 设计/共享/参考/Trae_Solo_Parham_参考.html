SwiftUI iOS 17+ Swift 6 @Observable MVVM Design Tokens

🎯 任务目标

ClawPilot 客户端基本功能已开发完成，现在进入 UI 优化阶段。目标：让 ClawPilot 的 UI 风格、布局、组件全面对齐 Parham-dev/OpenClaw-ios 这个 SwiftUI 项目。

Parham 的设计是工程师向但极致精致、克制、细节满满。把它的设计系统、组件库、架构约定引入 ClawPilot，作为 UI 优化的基线。

📌 参考源仓库：https://github.com/Parham-dev/OpenClaw-ios
📌 必读文档：仓库根目录的 README.md 和 CLAUDE.md
📌 真实截图：仓库 resources/ 目录下 7 张真机截图

1️⃣ 第一步：Clone Parham 仓库读源码

# Clone 下来
git clone https://github.com/Parham-dev/OpenClaw-ios.git
cd OpenClaw-ios

# 用 XcodeGen 生成 .xcodeproj（项目没有预生成）
xcodegen generate

# 打开 Xcode 编译运行（先 iOS 17+ 模拟器）
open OpenClaw.xcodeproj

在 Xcode 里先看 Parham 实际跑起来的样子，再开始改造 ClawPilot。一定要跑起来看，不能只看截图。

3️⃣ 设计系统（Design Tokens）

绝对禁止写字面量，所有尺寸/颜色/字号必须用 Design tokens：

// ✅ 正确
.padding(Spacing.md)
.frame(width: AppRadius.card)
.foregroundStyle(AppColors.success)
.font(AppTypography.heroNumber)

// ❌ 错误 —— 禁止
.padding(16)
.frame(width: 16)
.foregroundStyle(.green)
.font(.system(size: 34, weight: .bold))

Spacing（4pt 网格）

enum Spacing {
    static let xxs: CGFloat = 4
    static let xs: CGFloat = 8
    static let sm: CGFloat = 12
    static let md: CGFloat = 16
    static let lg: CGFloat = 24
    static let xl: CGFloat = 32
    static let xxl: CGFloat = 48
}

AppColors

enum AppColors {
    static let success      // 绿 —— 成功/在线
    static let danger       // 红 —— 失败/危险
    static let metricPrimary // 蓝 —— 主指标
    static func gauge(percent: Double, warn: Double, critical: Double) -> Color
}

AppTypography

enum AppTypography {
    static let heroNumber  // 大数字（指标卡）
    static let cardTitle   // 卡片标题
    static let actionIcon  // 操作按钮图标
    static let badgeIcon   // 徽章图标
    static let statusIcon  // 状态点
    static let nano        // 极小文字
}

AppRadius

enum AppRadius {
    static let sm: CGFloat = 8
    static let md: CGFloat = 10
    static let lg: CGFloat = 12
    static let card: CGFloat = 16
}
✅ 复用建议：Parham 项目里这些枚举都已实现并导出，直接 import 复用即可，或者把对应文件拷到 ClawPilot 项目里。

5️⃣ 架构约定（必须遵守）

5.1 ViewModel 必须继承 LoadableViewModel

@Observable
@MainActor
final class MyFeatureViewModel: LoadableViewModel<MyData> {
    init(repository: MyRepository) { super.init() }
    override func start() async { /* 加载逻辑 */ }
}

LoadableViewModel<T> 提供：data、isLoading、error、isStale、start()、refresh()、cancel()、startPolling(interval:)、stopPolling()。功能 VM 是它的一行子类。

5.2 Repository 必须用 Protocol 注入

protocol MyRepository {
    func fetch() async throws -> MyData
}
final class RemoteMyRepository: MyRepository {
    /* 实现 */
}
❌ 禁止在 View 或 ViewModel 里直接 new Repository。必须 Protocol 注入，方便测试和替换。

5.3 View 接收注入

struct MyView: View {
    @State private var viewModel: MyViewModel
    init(repository: any MyRepository) {
        _viewModel = State(initialValue: MyViewModel(repository: repository))
    }
    var body: some View {
        CardContainer(content: { ... })
    }
}

5.4 DTO 和 Domain model 分离

  • DTO：放在 Core/Networking/DTOs/，带 DTO 后缀，纯 Decodable
  • Domain model：放在 Feature 文件夹里，有 init(dto:) 转换器

5.5 其他必须遵守的规范

  • 📏 文件不超过 300 行，超过就拆分
  • 📱 iOS 17+ 部署目标，使用 Swift 6 模式（@Observable、strict Sendable）
  • 🔄 并发：所有 ViewModel 加 @MainActor。Loader 闭包用 @Sendable。用 actor 做缓存（MemoryCache）。不用 @unchecked Sendable。
  • 📋 日志：用 os.Logger，subsystem 是你的 bundle id，不用 print()
  • ♿ 无障碍：所有自定义视觉组件加 .accessibilityElement + .accessibilityLabel
  • 📳 触感：用户操作反馈用 Haptics.shared（刷新、保存、错误）
  • 💀 危险区：破坏性操作（重置、删除）必须先弹 Alert 确认
  • 🧪 分页：用 limit/offset + "Load More" 按钮。Append 时按 ID 去重
  • 🔤 Markdown 渲染：Markdown(text).markdownTheme(.openClaw)，不用 AttributedString(markdown:)
  • 📊 Token 格式化：Formatters.tokens()，别自己造
  • 💲 费用格式化：Formatters.cost()（USD）
  • 🕒 时间格式化：Formatters.relativeString(for:) / absoluteString(for:)

6️⃣ ClawPilot UI 改造清单

P0 — 必须做（决定整体观感）

① Home Dashboard（主页）

  • 用 CardContainer 重新做所有卡片
  • 系统健康卡：含 gauge(percent:warn:critical:) 颜色（CPU/RAM/磁盘）
  • Token 用量卡：含 TokenBreakdownBar 比例条 + 图例
  • Cron 摘要卡：用 CronStatusBadge
  • 快捷命令网格：3 列 × 2 行 = 6 个 CommandButton

② Chat 流式聊天

  • 用户消息气泡：.background(AppColors.metricPrimary)，圆角 16
  • 助手消息 Markdown：Markdown(text).markdownTheme(.openClaw)
  • 加载动画：3 个 6pt 圆点脉冲（不用菊花转）
  • 长响应用 ElapsedTimer 实时显示耗时
  • 输入栏用 CommentInputBar 模式（带附件/图片/语音图标 + 发送按钮）
  • 空打字机状态显示"正在思考..."

③ Crons（定时任务）

  • 顶部 DetailTitleView 显示 "5 jobs · 0 failed"
  • Segmented Control：Jobs / History
  • Jobs 列表用 CronStatusBadge（ENABLED/PAUSED/FAILED）
  • 每个任务显示 Cron 表达式 + 用的模型（用 ModelPill）
  • 失败的任务显示 "Investigate with AI" 按钮

④ Memory & Skills

  • 顶部 DetailTitleView 显示 "8 files · 10 skills"
  • Segmented：Memory / Skills
  • Markdown 渲染用 MarkdownUI
  • 段落实时评论（点击段落 → CommentSheet(.paragraph)）
  • 段落评论高亮（橙色 3px 左边框 + 浅橙背景）

⑤ Settings（设置）

  • Gateway 状态卡（绿点 + IP + 版本）
  • 外观分组：深色模式 Toggle、主色调选择（4 个 Color circle）
  • AI 模型分组：默认模型、参数设置
  • 危险区：重置所有设置（红色文字）

P1 — 应该做（提升专业感）

⑥ Sessions（会话）

  • 主会话卡：状态点 + 上下文窗口环形图（28% / 149k tokens）
  • Sub-agent 列表用紧凑的列表行

⑦ Token 详情页

  • 多个 TokenBreakdownBar（按模型分）
  • 折线图（用 Charts 系统框架，Parham 已用）

⑧ Loading / Error 状态

  • 所有异步数据：加载中显示 CardLoadingView（带 .shimmer()）
  • 错误显示 CardErrorView（带重试按钮）

P2 — 可选锦上添花

⑨ Haptics（触感反馈）

  • 刷新、保存、错误时调用 Haptics.shared

⑩ Accessibility（无障碍）

  • 自定义视觉组件加 .accessibilityElement(children: .combine) + .accessibilityLabel("...")

⑪ iPad 适配

  • 用 NavigationSplitView 替代 NavigationStack（侧边栏 + 详情）

7️⃣ 具体改造步骤

  1. git clone https://github.com/Parham-dev/OpenClaw-ios.git，通读 CLAUDE.md
  2. 打开 Xcode 模拟器，看 Parham 实际跑起来的样子
  3. 把以下文件/目录直接拷到 ClawPilot 项目里（保持文件结构）： 
    Sources/Core/DesignSystem/      # 全部 5 个文件
Sources/Core/Components/        # 全部 17 个组件
Sources/Core/LoadableViewModel.swift
  4. ClawPilot 现有的 ViewModel 全部改成继承 LoadableViewModel<T>
  5. ClawPilot 现有的 View 全部按上面的 P0/P1/P2 清单改造
  6. 每改一个模块，跑模拟器看效果，对比 Parham 的截图调整
  7. 保持 ≤300 行/文件 的限制
  8. 完工后生成一份 UI 改造说明

8️⃣ 禁止做的事

❌ 写字面量 — .padding(16) 改成 .padding(Spacing.md)
❌ 直接 new Repository — 必须 Protocol 注入
❌ 用 URLSession.shared 做长请求 — 用专用 session（15min timeout）
❌ 用菊花 loading — 用 shimmer skeleton 或 3 圆点
❌ 用 print() — 用 os.Logger，subsystem 是你的 bundle id
❌ 用 @unchecked Sendable — 用 actor 或 @MainActor
❌ 复制粘贴大段代码 — 先看 Parham 有没有现成组件

9️⃣ 验收标准

UI 优化完成后，ClawPilot 客户端应该：

  • ✅ 跟 Parham OpenClaw-ios 在视觉上几乎一致（布局、间距、配色、组件、状态处理）
  • ✅ 文件结构遵循 Core/ + Features/ 模式
  • ✅ 所有 ViewModel 继承 LoadableViewModel<T>
  • ✅ 所有 View 使用 Design tokens
  • ✅ 加载/错误状态用统一组件
  • ✅ 流式聊天有 ElapsedTimer
  • ✅ Token 显示有 BreakdownBar
  • ✅ 设置页有分组 + 危险区
  • ✅ 单文件不超过 300 行
