# MyPilot Icon — Final Spec (方案 A)

## 设计概念

**形态语言**：三条渐缩的圆角胶囊 + 右下角一个实心圆点
**设计哲学**：
- 弱化具象字母 M，用"层次 + 激活点"的几何语义
- 三条递减的横条象征 AI 思考的"展开 → 聚焦 → 结论"过程
- 右下角圆点象征"当前焦点 / 实时激活状态"
- 整体留白充足、现代、克制

## 几何规范

画布：`viewBox="0 0 100 100"`

| 元素 | 坐标 | 尺寸 | 圆角 |
|------|------|------|------|
| 第 1 条（最长） | x=14, y=20 | w=72, h=14 | rx=7 |
| 第 2 条（中长） | x=14, y=43 | w=50, h=14 | rx=7 |
| 第 3 条（最短） | x=14, y=66 | w=32, h=14 | rx=7 |
| 圆点（焦点） | cx=86, cy=73 | r=7 | — |

**视觉比例**：
- 三条横条总高度：48pt（含间隙 9pt）
- 圆点与第 3 条右端水平距离：约 40pt
- 圆点与第 3 条垂直居中对齐

## 色彩系统

### 推荐主色：系统蓝 `#007AFF`
- 浅色模式：`#007AFF`
- 深色模式：`#0A84FF`

### 备选色
| 场景 | 色值 |
|------|------|
| App 图标（彩色） | `#007AFF` 背景 + `#FFFFFF` 元素 |
| 菜单栏单色（浅色模式） | `#1D1D1F` |
| 菜单栏单色（深色模式） | `#FFFFFF` |
| 禁用态 | `#8E8E93` (50% 透明) |

## 尺寸规范

| 用途 | 尺寸 | 圆角 |
|------|------|------|
| App Store | 1024×1024 | 22% |
| macOS Dock | 128×128 | 22% |
| iOS 主屏 | 180×180 | 20% |
| 菜单栏 | 22×22 | — |
| 通知中心 | 32×32 | 12% |
| 列表内嵌 | 16×16 | 8% |

**最小可识别尺寸**：16pt（再小则圆点开始模糊）

## 使用规范

### ✅ DO
- 保持原始几何比例，禁止拉伸变形
- 浅色背景使用深色元素，深色背景使用浅色元素
- 圆点必须保留（是品牌识别核心元素）
- 在 16pt 以下场景可隐藏圆点，保留三条横条

### ❌ DON'T
- 不要添加阴影、立体效果、渐变
- 不要旋转或镜像
- 不要替换圆点为其他形状
- 不要在图标上叠加文字

## 应用示例

### macOS App Icon
- 圆角矩形 1024×1024
- 背景：`#007AFF`
- SVG 居中显示，元素填白色 `#FFFFFF`
- SVG 缩放至图标内 60%（含安全边距）

### 菜单栏图标
- 单色 22×22pt
- 浅色模式：黑色 `#1D1D1F`
- 深色模式：白色 `#FFFFFF`
- 可省略圆点以适应更小尺寸

### 文档/官网 Logo
- 完整几何（带圆点）
- 高度建议 ≥ 24pt
- 旁注文字 "MyPilot" 时间距 ≥ 8pt
