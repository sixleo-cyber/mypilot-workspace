我需要分析这个项目的整体架构。MyPilot 是一个 macOS 原生客户端应用，通过 WebSocket 连接到 OpenClaw Gateway。让我从几个层面来分析...

这是一个典型的客户端-服务端架构，主要分为三层：

📱 客户端层 (MyPilot App)

macOS 原生 SwiftUI 应用，负责 UI 渲染、消息管理、本地持久化

🔗 中继层 (MyPilot Link)

Node.js daemon，负责 WebSocket 中继、设备身份管理

🧠 AI 引擎 (OpenClaw Core)

模型推理、Agent 调度、工具执行
