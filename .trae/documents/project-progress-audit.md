## 二、Bug 修复记录

| Bug | 修复日期 | 根因 |
|-----|---------|------|
| 带附件消息报 `must be string` | 2026-05-26 | Gateway 期望 message 字段，Swift 发的是 content |
| 附件发送失败 | 2026-05-26 | daemon 查 frame.attachments（复数），Swift 发 frame["attachment"]（单数） |
| 图片发送不工作 | 2026-05-26 | daemon 图片转 ContentPart 数组但 Gateway 期望字符串；缺 media Capabilities |
| 文件上传无反应 | 2026-05-26 | REST 上传缺 Authorization header，错误被三层静默掩盖 |
| 非图片文件 AI 无法识别 | 2026-06-06 | daemon 只在 image/ 分支内读取 uploads/，非图片被跳过 |
| Markdown 文件发送后 AI 只收到 "." | 2026-06-06 | daemon 静默丢弃无 url 的 base64 附件 |
| AI 生成图片不显示 | 2026-06-06 | 缺 workspace 文件服务端点 |
| 发消息无响应 + 新建会话一直加载 | 2026-06-06 | send 在非主线程读 currentAgentId 竞态；@State 持有 wsService 观察链断裂 |
| 新建会话按钮不可见 | 2026-06-06 | 按钮被双重条件守卫包裹 |
| sessions.abort 失败 | 2026-06-06 | daemon 传 sessionKey 但 Gateway 期望 key |
| lifecycle end 导致消息丢失 | 2026-06-06 | daemon 收到 lifecycle end 后立即删除 pendingRequests，后续 chat 事件找不到 |
| Agent 文件编辑页面显示不全 | 2026-06-06 | NavigationSplitView 嵌套在 NavigationStack 中导致侧边栏被压缩 |
| 文档内容撑大窗口 | 2026-06-06 | TextEditor 无高度约束，改用 GeometryReader + ScrollView 限制 |
