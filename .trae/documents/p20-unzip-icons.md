# 解压覆盖 mypilot-icons.zip

## 操作
将 `/Users/liaoxing/Downloads/未命名文件夹/mypilot-icons.zip` 解压覆盖到 `/Users/liaoxing/Downloads/未命名文件夹/mypilot-icons-svg/`

## 命令
```bash
cd /Users/liaoxing/Downloads/未命名文件夹 && unzip -o mypilot-icons.zip
```

`-o` 参数：覆盖已有文件不提示

## 结果
- 原有 32 个 SVG 文件被覆盖
- 新增 31 个 `.fill` 变体 SVG + `mp.stop.outline.svg` + `README.md`
