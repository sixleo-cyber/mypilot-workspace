用户问的是 SwiftUI 在 iPad 上的多列布局。Apple 推荐 NavigationSplitView，它原生支持 iPad 的双栏/三栏展示。
iPad 上如何实现分栏布局？
🤖
iPad 推荐使用 NavigationSplitView，它在 iPhone 上自动折叠为单栏，在 iPad 上展开为双栏或三栏。
能给我一个最小可运行的例子吗？
🤖

  SidebarView()
} detail: {
  DetailView()
}
